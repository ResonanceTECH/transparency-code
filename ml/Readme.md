# Резонанс · ml

Отдельного ML-сервиса в текущей версии нет, и это осознанное решение. Проверки комплектности и противоречий реализованы детерминированными правилами на backend (`backend/app/domains/profile/rules.py` и `backend/app/domains/analysis/rules/`). Одинаковый вход дает одинаковый результат, причина каждого сигнала видна пользователю, а решение принимает проверяющий. Папка зарезервирована под возможные модели следующих этапов, например оценку качества сканов или сопоставление сведений с открытыми источниками.

Основная документация в [корневом README](../README.md).
