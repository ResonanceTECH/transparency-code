# Один текущий интерфейс с API · 20.11.2026

## Результат

По просьбе пользователя старый интерфейс дел удалён из `fullstack/frontend`. Основной адрес — **`/`**. `/prototype` оставлен совместимой ссылкой на то же приложение, а не вторым интерфейсом.

Все роли проходят через один `FinancialProfileGate` → `FinancialProfile`: резервист работает со своим профилем, reviewer/specialist — только с назначенными представленными материалами. Специалист больше не переключается на старый UI дел.

## Изменения

- В `src/main.tsx` нет импорта старого App и ветвления по pathname.
- Удалены старые `App.tsx`, `views.tsx`, `model.ts`, `profile.tsx`, `format.ts`, `types.ts`, `ui.tsx`, `styles.css` из `src/app/`.
- Общий same-origin транспорт перенесён без изменения контрактов в `src/shared/api.ts`; все профильные импорты обновлены.
- Добавлен самостоятельный `src/base.css`; текущий профиль и форма входа используют собственные дизайн-переменные, без зависимости от старых стилей. Неиспользуемый Lato исключён из импортов/зависимостей.
- `npm run dev` открывает текущий интерфейс на порту 4173; `dev:prototype` — совместимая команда того же запуска.
- Обновлены название страницы, README, актуальные отчёты и описание для Дарьи. ZIP пересобирается из текущего дерева без `src/app/`.

## Что сохранено

Backend, миграция `c72f6a904e11`, контракт `questionnaire-v1`, БД, сессии, пользователи и оригиналы файлов не изменены этой очисткой. Прежние API дел остались на сервере, но отдельного frontend для них больше нет. Соседние исходники/экспорты, GitHub и удалённое развёртывание не затронуты. Предыдущий ZIP сохраняется отдельной резервной копией перед заменой.

Все API-соединения текущего интерфейса, приватные черновики, версии, оценки, решения, история, контакты и сообщения сохранены. Единая печать A4 и три учебных шаблона не заменены старым механизмом отчётов.

## Проверки

`npm.cmd run typecheck` и `npm.cmd run build` прошли. В исходниках текущего UI не осталось импортов `src/app`, вызовов API дел и старой оболочки. Сверка с предыдущим ZIP подтверждает совпадение всех **88** backend-файлов, кроме отдельно обновлённых Markdown-инструкций; package.json и lock согласованы.

Локальные `/` и `/prototype` возвращают 200 и один HTML; контрольная сумма отдаваемого HTML совпадает с новой сборкой. Её JS доступен, `/api/health` отвечает `ok`, OpenAPI содержит 48 путей и `questionnaire-v1`. Это проверка доступности/статических артефактов без входа и сценарных изменений данных, не функциональный тест. ZIP сверяется с текущими исходниками и не включает `src/app/`.

**Тесты не запускались.** Исторические pytest/Playwright/capture/CI сохранены, но не подтверждают новый API. `frontend/tests/flow.spec.ts` и старый e2e-workflow описывают удалённый интерфейс и требуют актуализации, а не запуска как проверки нового UI.
