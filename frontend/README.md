# Резонанс · frontend

Клиентская часть full-stack проекта. Общая инструкция — в корневом [README.md](../README.md).

```bash
npm ci
npm run dev
```

Открыть **`http://127.0.0.1:4173/`**. `/prototype` и команда `dev:prototype` оставлены для совместимости и открывают тот же интерфейс. Для всех профильных операций нужен backend на порту 8000 с контрактом `questionnaire-v1` и актуальной миграцией.

Кнопка «Печать» формирует единую анкету всех вкладок; «Шаблоны и памятки» — три отдельные учебные заготовки. Согласие на обработку ПДн загружается подписанным сканом.

Один `FinancialProfileGate` → `FinancialProfile` используется для всех ролей: reservist — собственный профиль, reviewer/specialist — назначенные представленные материалы. Старый `src/app/` с делами и документным анализом удалён; общий API-транспорт — в `src/shared/api.ts`, независимые базовые стили — в `src/base.css`. Backend и его данные не удалялись.

Профиль, файлы, версии, оценки, комментарии и аудит сохраняются через API. После перезагрузки читается серверное состояние; «сохранено» появляется только после подтверждения. При конфликте ревизии выгрузите локальную JSON-копию, затем обновите профиль.

Тесты запускались: `test:prototype` — 2 passed / 21 failed, `test:visual` — 0/4, `test:e2e` — 0/5 (нет стека на :8080). Падения вызваны тем, что старые сценарии рассчитаны на встроенный in-memory демо-сценарий и подмену только авторизации; текущий интерфейс получает пустой профиль из API, а `flow.spec.ts` описывает удалённый UI. `typecheck`/`build` проходят.
