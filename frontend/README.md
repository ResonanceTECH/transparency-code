# Резонанс · frontend

Клиентская часть full-stack проекта. Общая инструкция — в корневом [README.md](../README.md).

```bash
npm ci
npm run dev
npm run dev:prototype
```

Открыть `http://127.0.0.1:4173/prototype` после `npm run dev:prototype`. Для входа нужен backend на порту 8000.

Кнопка «Печать» формирует единую анкету всех вкладок; «Шаблоны и памятки» — три отдельные учебные заготовки. Согласие на обработку ПДн загружается подписанным сканом.

`/prototype` авторизуется через API, но данные сценария живут в памяти страницы. Меняйте учебные аккаунты через «Выйти» и вход в той же вкладке, без перезагрузки. Маршрут `/` сохраняет данные через отдельный API-клиент и не включает все новые возможности макета.

Подробности и тесты — в [корневом README](../README.md), [состоянии клиента](../docs/reports/client-status.md) и [сверке двух документов требований](../docs/reports/requirements-reconciliation-2026-11-19.md).
